# คลังความรู้ RAG สำหรับ NPC และ GM

ให้ NPC (เช่น พระฤาษีแห่งอโยธยา, หนุมาน, ทศกัณฐ์) หรือ GM ตอบคำถามผู้เล่นเรื่องตำนาน เควส สกิล และการคราฟต์ โดยตอบจากข้อมูลในคลังนี้เท่านั้น ไม่แต่งเรื่องเอง

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `schema/knowledge_base.schema.json` | JSON Schema ของข้อมูล 4 แบบ: `lore_entity` (ตัวละคร สถานที่ ของวิเศษ), `combat_skill`, `crafting_recipe`, `quest` และ `chunk` (ข้อความยาว) |
| `data/knowledge_base.json` | ข้อมูลแบบมีโครงสร้าง 13 รายการ: พระราม, หนุมาน, ทศกัณฐ์, นครอโยธยา, ป้อมลงกา, สกิลห่าศรพรหมาสตร์, สกิลพุ่งหอกโมกขศักดิ์, สูตรศรศักดิ์สิทธิ์, สูตรหอกโมกขศักดิ์ ฯลฯ |
| `data/chunks.jsonl` | ข้อความตัวอย่าง 6 ชิ้น (3 เรื่อง × ไทย/อังกฤษ): อโยธยา, กลไกป้อมลงกา, ผลึกวิญญาณและเควสดวงใจทศกัณฐ์ |
| `rag_npc.py` | สคริปต์ RAG: ฝังคำถามเป็นเวกเตอร์ → ค้นข้อมูลที่ใกล้ที่สุด → สร้าง system prompt ของ NPC → (เลือกได้) ให้ Claude ตอบ |

## ใช้งาน

ไม่ต้องติดตั้งอะไรเพิ่ม (ใช้ Python 3.10 ขึ้นไป)

```bash
python3 rag/rag_npc.py --selftest
python3 rag/rag_npc.py "ทศกัณฐ์เกิดทุกกี่นาที" --npc sage
python3 rag/rag_npc.py "How do I craft Holy Arrows?" --npc gm --json
```

ให้ Claude ตอบเป็น NPC จริง (เสียค่า API ต่อคำถาม):

```bash
python3 -m pip install anthropic
export ANTHROPIC_API_KEY=...   # ห้ามใส่คีย์ในโค้ดหรือ commit
RAG_USE_CLAUDE=1 python3 rag/rag_npc.py "หอกโมกขศักดิ์ทำยังไง" --npc hanuman
```

ตัวเลือก: `--npc sage|hanuman|thotsakan|gm`, `--top-k 4`, `--max-spoiler 0|1|2`, `--live-only` (ซ่อนของที่ยังไม่เปิดในเกม)

## กติกาของข้อมูล

- `status: live` = มีในเกมแล้ว, `planned` = ยังเป็นแผน NPC จะบอกว่า "เร็ว ๆ นี้" ไม่บอกว่าทำได้แล้ว
- ตอนนี้ของที่ live: นครอโยธยา, ร้านค้า, เควสถวายแหวน, ประตูลงกา, กุมภกรรณ, ทศกัณฐ์ ส่วนผลึกวิญญาณ, เควสดวงใจ, สูตรคราฟต์, สกิลใหม่ และถนนข้ามทะเล ยังเป็น planned
- `spoiler_level` 0 สาธารณะ, 1 ใบ้, 2 เฉลยเต็ม ขั้นเควสที่เป็นใบ้หรือเฉลย (ระดับ 1-2) ไม่ถูกส่งให้ NPC เลย ผู้เล่นจะได้ไม่โดนสปอยล์
- ตัวเลขในเกม (เลเวล, HP, ราคา, เวลาเกิด) ต้องตรงกับ `custom/db/` และ `custom/npc/ramakien.txt` ถ้าแก้เกมต้องแก้ที่นี่ด้วย
- ในข้อความใช้ชื่อเมืองของเรา (อโยธยา, ลงกา) ชื่อแผนที่ของเซิร์ฟเวอร์อยู่ใน `game_ref` เท่านั้น เนื้อหาตำนานเขียนใหม่ด้วยคำของเราเองจากรามเกียรติ์ซึ่งเป็นวรรณคดีสาธารณะ

## เพิ่มข้อมูล

1. เพิ่มรายการใน `data/knowledge_base.json` หรือบรรทัดใหม่ใน `data/chunks.jsonl` (ทำทั้ง `.th` และ `.en`)
2. เพิ่มคำถามทดสอบใน `SELFTEST` ของ `rag_npc.py` แล้วรัน `--selftest`

## ข้อจำกัดและทางขยาย

- ตัวค้นหาเป็น TF-IDF แบบ character n-gram เพราะภาษาไทยไม่มีช่องว่างระหว่างคำ ทำงานในเครื่องได้ทันที แต่จับคำพ้องความหมายไม่ได้ และคำถามนอกเรื่องอาจได้ผลค้นหาอ่อน ๆ มาบ้าง ตัวกันคือกฎใน prompt ที่ให้ NPC ตอบว่า "ไม่ทราบ" เมื่อข้อมูลไม่ตอบคำถาม
- ถ้าข้อมูลเกิน ~500 ชิ้น หรืออยากให้ถามไทยแล้วเจอข้อความอังกฤษ ให้เปลี่ยน `TfidfIndex` เป็นโมเดล embedding หลายภาษา (เช่น multilingual-e5) และเก็บเวกเตอร์ใน pgvector หรือ Qdrant โดยคง `search()` ไว้เหมือนเดิม
- การต่อเข้าเกมจริง (NPC ในเซิร์ฟเวอร์เรียก API) ต้องมีบริการกลางอีกชั้น เพราะตัวเกมแสดงได้แค่ภาษาอังกฤษตอนนี้ ยังไม่ได้ทำในงานนี้
