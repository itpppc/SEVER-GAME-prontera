1ดาวน์โหลดตัวติดตั้ง

Install-Prontera.bat

ตัวติดตั้งคลิกเดียวสำหรับ Windows 10 / 11 ไฟล์เล็กไม่ถึง 100 KB

ดาวน์โหลดตัวติดตั้ง
  • ต้องมี: Windows 10 หรือ 11, พื้นที่ว่างประมาณ 10 GB, อินเทอร์เน็ตที่โหลดไฟล์ใหญ่ได้
  • ไฟล์นี้ไม่มีตัวเกมอยู่ข้างใน มันจะโหลดตัวเกมจากผู้ให้บริการต้นทางลงเครื่องคุณเอง แล้วตั้งค่าให้ต่อเซิร์ฟเวอร์ของเรา
  • ถ้าเบราว์เซอร์ถามว่าจะเก็บไฟล์ไหม ให้กด เก็บไว้ (Keep)

2ติดตั้ง

  1. ดับเบิลคลิก Install-Prontera.bat ถ้าขึ้น "Windows protected your PC" ให้กด More info แล้ว Run anyway
  2. Windows จะขอสิทธิ์ติดตั้งโปรแกรมที่จำเป็น กด Yes
  3. ตัวติดตั้งตัวเกมเป็นภาษาเกาหลี กดปุ่มขวาล่างไปเรื่อย ๆ ตอนเลือกโฟลเดอร์ให้ใช้ C:\RO และหน้าสุดท้ายเอาติ๊กที่จะเปิดเกมออก
  4. ถ้าหน้าต่างดำถาม Do you want the CDClient DLL copied as well? พิมพ์ y แล้วกด Enter
  5. เมื่อขึ้น Done! จะมีไอคอน Prontera บนเดสก์ท็อป

ห้ามเปิดตัวอัปเดตภาษาเกาหลี (หน้าต่างที่มีปุ่ม START) เพราะจะเปลี่ยนไฟล์เกมจนเข้าเซิร์ฟเราไม่ได้ ให้เปิดเกมจากไอคอน Prontera เท่านั้น

  • เน็ตหลุดระหว่างโหลด: ดับเบิลคลิกตัวติดตั้งอีกครั้ง จะโหลดต่อจากเดิม ขั้นที่เสร็จแล้วจะข้ามให้
  • บันทึกการติดตั้งอยู่ที่ C:\RO-tools\install-log.txt ถ้าติดปัญหาส่งไฟล์นี้ให้ทีมงาน

3สมัครไอดี (ในหน้าล็อกอินของเกม)

เปิดเกมจากไอคอน Prontera แล้วสมัครที่หน้าล็อกอินได้เลย

  1. ช่อง ID พิมพ์ชื่อที่ต้องการ ตามด้วย _M (ตัวละครชาย) หรือ _F (ตัวละครหญิง) เช่น hanuman01_M
  2. ช่อง Password ตั้งรหัสผ่านที่ต้องการ แล้วกดเข้าสู่ระบบ ระบบจะสร้างไอดีให้ทันที
  • ชื่อไอดี (ไม่นับ _M/_F) และรหัสผ่าน ต้องยาว 6 ตัวขึ้นไป ใช้ตัวอักษรอังกฤษและตัวเลข
  • สมัครได้ 1 ไอดีต่อ 10 วินาที ถ้าขึ้น "Rejected from server" ให้รอสักครู่แล้วลองใหม่
  • ทีมงานจะไม่ขอรหัสผ่านของคุณไม่ว่ากรณีใด

4เข้าเกม

  1. ล็อกอินอีกครั้งด้วยชื่อไม่ต้องมี _M/_F เช่น hanuman01
  2. เลือกเซิร์ฟเวอร์ Prontera
  3. ตั้งรหัส PIN 4 หลัก (จำไว้ ใช้ทุกครั้งที่เข้าเกม)
  4. สร้างตัวละคร แล้วเริ่มผจญภัยที่เมืองพรอนเทรา

ดูเรทและตารางกิจกรรม

แก้ปัญหาที่พบบ่อย

กดไอคอนแล้วขึ้นหน้าต่างเกาหลีที่มีปุ่ม START

นั่นคือตัวอัปเดตของเกมต้นฉบับ ห้ามกด START ปิดหน้าต่างด้วย Ctrl+Shift+Esc แล้วคลิกขวา Ragnarok เลือก End task จากนั้นดับเบิลคลิกตัวติดตั้งอีกครั้ง มันจะซ่อมไอคอนและไฟล์เกมให้

ตัวติดตั้งขึ้น data.grf cannot be used หรือเกมเด้งออกทันที

ไฟล์เกมถูกตัวอัปเดตแก้ไปแล้ว พิมพ์ Y แล้วกด Enter ตัวติดตั้งจะลงเกมชุดใหม่ให้โดยไม่ลบโฟลเดอร์เดิม และใช้ไฟล์ที่โหลดไว้แล้ว

ขึ้น error MSVCP140.dll หรือ VCRUNTIME140.dll

ติดตั้ง Microsoft Visual C++ 2015–2022 Redistributable รุ่น x86 จากเว็บไซต์ Microsoft แล้วเปิดเกมใหม่

Windows Defender ลบไฟล์ระหว่างติดตั้ง

กด Allow เฉพาะไฟล์นั้น (อย่าปิดแอนติไวรัสทั้งเครื่อง) แล้วดับเบิลคลิกตัวติดตั้งอีกครั้ง

ต่อเซิร์ฟไม่ได้ตั้งแต่หน้าล็อกอิน

ดูสถานะเซิร์ฟเวอร์ที่แถบด้านบนของเว็บ ถ้าเซิร์ฟเปิดอยู่แต่ยังเข้าไม่ได้ ให้รันตัวติดตั้งตัวล่าสุดจากหน้านี้อีกครั้ง เพราะที่อยู่เซิร์ฟเวอร์อาจเปลี่ยน

ปุ่มหรือรูปบางอันยังเป็นภาษาเกาหลี

ไม่กระทบการเล่น เมนูและไอเทมเป็นภาษาอังกฤษแล้ว

ยังแก้ไม่ได้? ติดต่อทีมงาน พร้อมแนบภาพหน้าจอและไฟล์ C:\RO-tools\install-log.txt
