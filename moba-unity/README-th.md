# ศึกลงกา MOBA (Unity) · ต้นแบบเล่นได้ 1v1

เกม MOBA 3D มุมกล้องเฉียงจากด้านบน ฝ่ายอโยธยา (พระราม) ปะทะ ฝ่ายลงกา (ทศกัณฐ์) 1 เลน มีป้อม 3 ชั้น แกนกลาง มินเนียน และบอทคู่ต่อสู้ เล่นฟรี ไม่มีเก็บเงิน

ตัวเลขทั้งหมด (สเตตัส สูตรดาเมจ มินเนียน ป้อม) ตามเอกสารใน `game-design/moba/` (FOUNDATION, ECONOMY-MAP, HERO-KITS) ภาพทั้งหมดสร้างจากโค้ด ไม่ใช้ไฟล์ภาพหรือเสียงของใคร

## ติดตั้งและเปิดเกม (Windows, วางคำสั่งเดียว)

เปิด PowerShell แล้ววางบรรทัดนี้ (ดู `Install-MobaUnity.ps1`):

```powershell
irm https://raw.githubusercontent.com/itpppc/SEVER-GAME-prontera/main/moba-unity/Install-MobaUnity.ps1 | iex
```

สคริปต์จะติดตั้ง Unity Hub และ Unity 6 LTS วางโปรเจกต์ไว้ที่ `F:\ProjectAI\SuekLanka-MOBA` แล้วเปิดให้ ครั้งแรกต้องล็อกอิน Unity ID ฟรี (Personal) หนึ่งครั้ง

เมื่อ Unity เปิดโปรเจกต์เสร็จ กดปุ่ม ▶ Play ด้านบน

## วิธีเล่น

| ปุ่ม | หน้าที่ |
|---|---|
| จอยซ้าย (ลากนิ้ว) หรือ WASD / ลูกศร | เดิน |
| ปุ่ม "โจมตี" หรือ Space | ตีปกติ (ถ้ายืนนิ่งจะตีเป้าที่อยู่ใกล้ให้เอง) |
| Q / E / R | สกิล 1 / สกิล 2 / ท่าไม้ตาย (เล็งอัตโนมัติไปที่ศัตรูใกล้สุด) |
| Esc | กลับเมนู |

- **พระราม:** Q ศรกระจาย 5 ดอก · E ก้าวเทพ (พุ่งไปทางที่ลากจอย) · R **ศรพรหมาสตร์** ชาร์จ 1.25 วิ แล้วยิงทะลุทั้งเลน (ศัตรูเห็นเส้นเตือน)
- **ทศกัณฐ์:** Q พระขรรค์ 3 จังหวะ · E คำรามลดพลังโจมตี · R ร่างยักษ์ 8 วิ · **กล่องดวงใจ:** กล่องซ่อนในป่า ตายใกล้กล่องแล้วไม่ตายจริง ศัตรูทุบกล่อง 5 ครั้งเพื่อทำลาย
- ชนะเมื่อทำลายแกนกลางของฝ่ายตรงข้าม ต้องตีป้อมตามลำดับ ด่านนอก → ด่านใน → ป้อมฐาน → แกนกลาง

## สร้างไฟล์เล่นบนเครื่อง

ในเมนู Unity ด้านบน เลือก **Ramakien > Build Windows (.exe)** (ได้ไฟล์ใน `Builds/Windows`) หรือ **Ramakien > Build Android (.apk)** (ต้องติดตั้งโมดูล Android ใน Unity Hub ก่อน)

## โครงสร้างโค้ด

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `Assets/Scripts/Sim/` | กติกาเกมล้วน ไม่แตะ UnityEngine (tick 30 Hz, เลขจำนวนเต็ม, RNG มี seed) รันเหมือนกันทุกเครื่อง ต่อออนไลน์ได้ภายหลัง |
| `Assets/Scripts/Game/` | ภาพ 3D, กล้อง, เสียงสังเคราะห์, เอฟเฟกต์, HUD, อินพุตสัมผัส |
| `Assets/Resources/` | shader การ์ตูน (ขอบม่วงเข้ม) และเอฟเฟกต์เรืองแสง |
| `Assets/Editor/` | ตั้งค่าโปรเจกต์อัตโนมัติ และเมนูสร้างไฟล์ |
| `SimTests/` | เทสต์ของกติกา รันด้วย `mcs -out:t.exe SimTests/Program.cs Assets/Scripts/Sim/*.cs && mono t.exe` |
